actually holds up when you implement it.

Python · TypeScript · React · Supabase · LLM APIs · BERTopic

### Projects

**[Baseline](https://baselineframework.dev)** — An age-appropriate AI
response framework for schools. Hard-coded safety gates, five declared
grade bands (K–1 through 11–12), and conversations framed as part of the
school-visible learning record rather than a private confidant.
*Built because "age-appropriate AI" is asserted constantly and specified
almost never. This is what it looks like when you actually write it down.*

**Proximal** — A guided-discovery scaffolding companion to Baseline,
grounded in Vygotsky's zone of proximal development. Conditions a model
on a teacher-authored unit plan, then runs multi-turn questioning that
leads students to construct understanding rather than supplying answers.
*Built to test whether learning-science principles survive contact with
a production LLM. Oriented toward learning outcomes, not engagement.*
